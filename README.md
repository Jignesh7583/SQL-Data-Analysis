# SQL-Data-Analysis
A SQL-based data analysis project for Alt Mobility, including customer behavior analysis, payment status analysis, and customer retention analysis using SQL and Power BI.

Project Overview: This project focuses on performing comprehensive SQL-based analysis for Alt Mobility, targeting order fulfillment, customer behavior, payment success, and customer retention.

Dataset Used: Two CSV files representing Orders and Payments datasets were uploaded into a MySQL database using XAMPP.

SQL Queries: Multiple SQL scripts were written to analyze:

Order status and revenue trends.

Customer behavior and repeat ordering.

Payment status success/failure rates.

Detailed order information (joining order and customer data).

Customer cohort retention analysis.

Tools Used:

MySQL via XAMPP (phpMyAdmin)

Power BI for visualization

Execution Steps:

Create MySQL tables and import CSV data.

Execute SQL queries for each task.

Export data results where needed for visualization.

Build visual dashboards using Power BI.
